# 本地绘本工作台

## 启动与配置

安装 pnpm 和支持 `node:sqlite` 的 Node.js，执行 `pnpm install --frozen-lockfile`。复制 `.env.example` 为 `.env.local`，填写文本和图片接口的地址、密钥及模型名，执行 `pnpm dev:local`。

访问 http://127.0.0.1:3100/custom 。工作台仅监听本机地址，本地流程不依赖 Supabase、登录、兑换码或次数额度。

文本配置为 `CUSTOM_BOOK_TEXT_BASE_URL`、`CUSTOM_BOOK_TEXT_API_KEY`、`CUSTOM_BOOK_TEXT_MODEL`；图片配置为 `CUSTOM_BOOK_IMAGE_BASE_URL`、`CUSTOM_BOOK_IMAGE_API_KEY`、`CUSTOM_BOOK_IMAGE_MODEL`。密钥只存在于服务端环境变量，不写入前端。模型未配置时仍可手动编辑和保存。

## 项目和保存

左侧“当前项目”切换项目，“新建 / 载入示例”创建独立项目，原有项目保留。输入后约 0.5 秒自动保存，也可点顶部“立即保存”。当前工作区、选中页、正文、图片版本和排版随项目恢复。

浏览器保留未写盘修改的恢复记录；浏览器缓存空间不足时，SQLite 保存仍继续。关闭页面前等待“已保存到本机”。同一项目在两个窗口编辑时使用修订号保护，旧窗口不会覆盖新窗口的内容。

默认数据保存在 `.local-data/`：

- `storybloom.sqlite`：项目、书页、生成任务、版本和修订号。
- `assets/`：上传及生成的图片。

每本绘本会在 `.local-data/绘本/<书名>/` 独立归档：`编导稿.txt`、`项目配置.json`、`图片/`、`成品PDF/` 和 `交付包/`。顶部“打开本书文件夹”直接打开当前项目的 Finder 文件夹；切换项目后入口随之切换。编导与图片自动更新，阅读 PDF、印刷 PDF 和交付包在导出后自动归档。重名项目自动区分，书名修改时已有文件一并保留；旧图和旧 PDF 放在历史版本中。

通过 `STORYBLOOM_LOCAL_DATA_DIR` 可指定数据目录。完整备份需先等待保存并停止服务，再复制整个目录；运行中的 WAL / SHM 文件不能随意删除。配置 JSON 不包含图片，跨电脑迁移需备份整个数据目录。

## 三个领域

1. **养成好习惯**：一次练习一个可观察行为，填写具体情境、孩子反应和家长陪伴步骤。
2. **真实经历改编**：保留时间地点人物、事情经过、确实说过的原话和允许加工范围。修改事实后需要重新确认。
3. **认知启蒙**：识图、识物、识字，填写目标概念或汉字、互动要求，识字可选择拼音。系统检查目标词覆盖，图物对应和拼音需人工复核。

每个领域有 20 个常用分场景。也可让 AI 按故事推荐；手动指定的场景在 AI 整理后保留。识图 / 识物 / 识字场景联动启蒙类型，已有项目的自定义场景仍可保存。

## 创作流程

1. 在“创作设定”选择领域与场景，填写孩子称呼、年龄和一段经历。参考照片可选，“照片与成书设置”里可指定正文页数；人物和画风等参数在高级设置。
2. 让 AI 整理设定，核对书名、人物和目标。真实经历先确认事实，再生成分镜。
3. 在“故事分镜”逐页检查正文、画面描述及人物。刷新后的待确认任务先点“载入待确认分镜”，确认后继续生图。
4. 在“单页画布”调整文字、场景、取景和排版。图片版本在独立页签中对比与恢复，正文或图片修改后撤销对应审核状态。
5. 校对全书后到“印刷交付”，选择输出与装订、检查质量，再导出文件。

正文支持 1–200 页，封面另计。长书先生成全书节奏，再按 8 页批次展开，已完成批次自动保存。减少页数会隐藏多余页，重新增加时恢复其正文、图片和版本。

生成任务、已完成步骤和远端任务编号保存在本机。中断或刷新后可继续任务，重试复用已有远端任务。模型生成内容仍需人工审核。

## 画布与图片版本

画布支持正文、场景、缩放、水平 / 垂直取景、文字位置、字号、版式和图片替换。跨页共用画面与排版，并标明关联页码。

每页最多保存最近 32 个不同图片引用。取景调整单独保存，不重复生成图片版本。对比在主工作面并排显示，选择历史版本后回到当前画布。当前打开期间可以撤销编辑；刷新恢复的是已保存的最新结果。

图文一体图片保留完整画面，不开放裁剪和外加字排版；修改图片中的文字需要重新生成或替换。可编辑模式的正文独立排版。

## A4 印刷交付

1. 选择印厂版或办公版，再选择左侧装订或骑马订。内外侧、上下留白、出血、字号和插图宽度均可调整并保存。
2. 点击“检查印刷质量”。按实际取景后的像素、印刷尺寸、有效 ppi、正文长度和字体字符覆盖进行检查。缺图或低于 300 ppi 时不允许正式导出。
3. 若需“准备高清插图”，会调用已配置的生图服务，原图保留在版本历史；每页完成即落盘，可继续未完成的页面。重绘后的内容、人物和文字需重新核对。
4. 检查通过后下载 A4 PDF 或印刷交付包。图文一体图片需先完成人工校对确认。

成品为 A4 竖版 210 × 297 mm。印厂版默认四边 3 mm 出血；办公版文件就是 A4，按实际大小打印。默认内侧 18 mm、外侧 12 mm、上下 15 mm，奇偶面镜像。可选裁切标记。

成册文件包含封面四面，并按双面或骑马订要求补白。交付包包含整本、内页、封面 PDF、高清插图、可编辑文稿、逐页清晰度报告和制作说明。骑马订办公交付包附 A3 横向双面拼版，用 A3 纸短边翻转后对折为 A4。

中文字体完整嵌入，正文为矢量文字。图片保留 RGB；有指定印厂 ICC、CMYK、PDF/X 或胶装书脊要求时，由制作人员按印厂要求处理。快速预览 PDF 用于阅读，不代替正式印刷导出。
